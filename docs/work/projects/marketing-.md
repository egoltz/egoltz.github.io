# Customer Opportunities
_Analysis in Python, visualization in Python and Tableau_

This was a client project originally started as a data hygene project after the PE-backed client acquired several new companies selling adjacent products. The task was to clean, deduplicate and standardize their data that had been compiled from several different company aquisitions. The project expanded to merge existing company data to an industry-specific national database, to enrich existing data, find revenue drivers and use that information to find potential new customers.
